Belajar Formatting Text pada HTML

HTML merupakan bahasa markup yang digunakan untuk membuat struktur halaman website.

Macam-Macam Formatting Text

1. Tag strong untuk memberikan penekanan penting. Ini contoh teks strong.

2. Tag b untuk membuat teks tebal. Ini contoh teks bold.

3. Tag em untuk memberikan penekanan. Ini contoh teks emphasis.

4. Tag i untuk membuat teks miring. Ini contoh teks italic.

5. Tag mark untuk menandai teks. Ini contoh teks highlight.

6. Tag small untuk membuat teks kecil. Ini contoh teks small.

7. Tag del untuk teks yang dihapus. Ini contoh teks del.

8. Tag ins untuk teks tambahan. Ini contoh teks ins.

9. Tag sub untuk teks di bawah. H2O

10. Tag sup untuk teks di atas. X2
